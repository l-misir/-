## 画面と操作

### メイン画面
| 操作 | 動作 |
|---|---|
| セルをタップ | +1（水色フラッシュ） |
| セルを長押し（300ms で赤） | −1。g/b/r は打ち始め値未満にならない |
| BIG/REG を +1 | その時点で当選記録を作成し、テンキーパネルを表示（回転数を入力） |
| BIG/REG を −1 | 同種の最新記録を削除（確認なし） |
| 機種名をタップ | ダミー表示 ON/OFF（ON 中は機種名が半透明。タップのたびにダミー値が変わる） |
| 機種名を長押し（550ms） | まとめて加算パネル |
| 左上 🔍 | 設定推測モーダル |
| 右上 ⚙️ | 設定モーダル |

レイアウト: 縦画面は1カラム、横画面は左右2カラム（右カラム=ランプ・レトロ）。スクロールなしで1画面に収める。

### テンキーパネル（大当たり回転数）
- 配置: 縦画面はスイカ付近に被せる、横画面は右カラムに被せる。履歴から編集する時は画面中央
- 配列 `7 8 9 / 4 5 6 / 1 2 3 / ⌫ 0 OK`、キー左・表示右
- 入力のたびに記録へ即反映。✕・外側タップ・OK のどれで閉じても値は残る
- 未入力で閉じると `g: null`（未入力）の記録になる

### まとめて加算パネル
- 項目（4列×2行）: G数 / BIG / REG / ベル / スイカ(前) / スイカR(ニューキングのみ) / レトロ達 / レトロ発
- 項目を選んでテンキーで数を入力 →「加算」。続けて別項目にも加算可
- 縦横とも上下配置（項目が上、テンキーが下）。横画面ではテンキーを縮めて1画面に収める
- 市販カウンターやiOSショートカットで数えた値をまとめて入れる用途

### ダミー表示
内部値は一切変えず、表示だけ置き換える。タップ操作も有効（内部値は増減する）。

| 対象 | ルール | 例 |
|---|---|---|
| ゲーム数 / BIG / REG | 変化なし | 3000 → 3000 |
| ベル / スイカ系 / レトロ系 | 前後に2桁ずつ付加 | 400 → 68**400**27 |
| ランプ類 | 前後に1桁ずつ付加 | 5 → 4**5**1 |

### 設定推測モーダル（🔍）
- ヘッダー左 📋 → 実戦履歴、ヘッダー中央「設定推測 📊」をタップ → 大当たり分析
- ＜推測設定＞ 設定別の確率バー
- ＜実践値＞ 総回転数 / 現在獲得枚数 / 高設定期待度 / 期待機械割 / 期待獲得枚数
- ＜詳細データ＞ 各要素の実測値。行タップで個別設定推測グラフ、ランプ行は長押しで色別行を展開

#### 設定推測の計算（`calc()`）
各要素の二項・多項尤度に要素調整の重み（`w/100` 乗）を掛けて積を取る。

```
totalL = BIG × REG × 合算 × ベル × BIGスイカ × REGスイカ × レトロ
       × BIG筐体ランプ × サイドランプ × REG筐体ランプ(下限示唆) × 朝一ランプ
```
BIG・REG・合算は情報が重複するが、ユーザーは重複前提で重みを調整しているので3つとも掛ける。

期待機械割は1位の1/10未満の設定を除外して正規化した確率で payout を加重平均する。

### 大当たり分析モーダル
タブ2つ。
- **当選履歴**: 全体 / BIG / REG 切替。上部に現在のハマりG数、統計（回数・平均・最大・最小、未入力は除外）、一覧（上が新しい）。G数タップで修正
- **確率表**: 設定タブ（初期値=推測1位、手動切替）。合算確率で「その回転数までに当たる確率」と実績（記録のうちその回転数以内だった割合）を並べる。実績が理論以上なら緑、未満なら赤
  - 行: 100G / 確率分母G / 80%到達G / 分母×2〜N倍（1000G未満）/ 90%到達G / 1000G を確率昇順
  - G数は切り上げ、確率は小数1位

### 設定モーダル（⚙️）
機種選択 / 個人・全て / タップ・入力モード / 打ち始めデータ / 朝一BIG筐体ランプ / 要素調整 / スプレッドシート連携（GAS URL・トークン）/ 「データ保存・画像出力」/ リセット

「データ保存・画像出力」: クリップボードへTSVコピー → GAS 設定済みならシート保存するか確認 → 画像生成するか確認。画像は Web Share API（共有シートから写真に保存）、非対応環境はダウンロード。

### 実戦履歴モーダル（📋）
- GAS から全シートを取得し、**現在選択中の機種のシートだけ**を表示
- 取得時に全行を `calc()` で再計算（要素調整の変更が過去データに反映される）
- 上部: 信頼度フィルタ（最低↑ / 低↑ / 中↑ / 高↑ / 最高↑ / 虹、単一選択）、推定設定フィルタ（全て＋機種の設定、複数選択、AND 条件）
- フィルタ結果で設定ツモ率の棒グラフを表示。条件外の行は**非表示**（暗くしない）
- 行タップで確認後、その日のデータをメイン画面へ復元

#### 信頼度
```
LLR = log(1位の尤度) − log(2位の尤度)
信頼度 = 1 − exp(−LLR / 2)
```
| ランク | 条件 |
|---|---|
| 最低 | < 10% |
| 低 | 10〜25% |
| 中 | 25〜50% |
| 高 | 50〜80% |
| 最高 | 80%以上（確定示唆なし） |
| 虹 | 最高設定の確定示唆あり（ニューキング=REG筐体紫、他=REG筐体虹）。信頼度の数値に関係なく |

境界は実データ（ニューキングⅤ 39日分）の分布から決めた: 最低56% / 低23% / 中10% / 高5% / 最高3% / 虹3%。
