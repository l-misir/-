# iOS ショートカット: 背面タップでカウント

カウンターアプリとは連携しない独立したカウンター。他アプリを見ていても背面ダブルタップで数えられ、数えた値はあとでカウンターの「まとめて加算」（機種名長押し）で入力する。

動作確認環境: iPhone SE（第3世代）/ iOS 18.7.8

## 前提
「ファイル」アプリ →「このiPhone内」→ 右上「⋯」→「新規フォルダ」で **`Shortcuts`** フォルダを作っておく（無いと保存も読み込みも失敗する）。

## ① ベルカウント（背面ダブルタップ）

```
count.txt のパスにある Shortcuts からファイルを取得
    見つからない場合はエラー: オフ
「ファイル」からテキストを取得
「テキスト」+ 1 を計算                 ← 「計算式」ではなく「計算」アクション
「計算結果」を Shortcuts に保存        ← パス count.txt / 上書き: オン
通知「計算結果」を表示
```

ハマりどころ:
- 「計算式」アクション（f(x)）はテキストの改行等で計算エラーになる。電卓アイコンの「計算」を使う
- 初回は `count.txt` が無いので、先にリセットを1回実行する

## ② リセット（コントロールセンター）

```
テキスト: 0
「テキスト」を Shortcuts/count.txt に保存（上書き: オン）
通知「🔄 リセット」を表示
```

コントロールセンター → 編集 → コントロールを追加 →「ショートカット」→ リセットを選択。トリプルタップは誤爆するので割り当てない。

## ③ 背面タップの割り当て
設定 → アクセシビリティ → タッチ → 背面タップ → ダブルタップ =「ベルカウント」、トリプルタップ = なし

## 制約（iOS 仕様で改善不可）
- 背面タップには約2秒のクールダウンがある
- 同じアプリからの連続通知はまとめられ、すぐ表示されないことがある（内部的には加算されている）
- 画面消灯中は反応しない
- 通知の代わりに「バイブレーション」アクションにすると即座に手応えが返る
